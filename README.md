# Galeria

**Galeria** is a small Windows tray app that turns your desktop wallpaper into a rotating gallery of public-domain paintings. Every few minutes it shows a new artwork, at your screen's resolution, with the title, artist, date and museum written in a corner. You learn about art passively, just by looking at your desktop.

*Português abaixo.*

## Features

- 976 well-known paintings (Bruegel, Leonardo, Vermeer, Rembrandt, Van Gogh, Klimt...), every one in the public domain and close to 4K resolution. Each one is shown once before any repeats.
- The image is composed at your monitor's exact resolution. Artworks whose shape doesn't match the screen are shown whole over a blurred background made from the same painting.
- Tray menu: **About this artwork** (opens its Wikipedia page), **Next artwork**, **Pause**, **Change every** (30 seconds to 1 day), **Quit**.
- The last 40 images are cached, so it keeps working offline.
- 11 languages for menus and captions: English (default), Português, Español, Français, Deutsch, Italiano, 中文, 日本語, العربية, 한국어, Русский. Change it in the tray menu under **Language**. Artwork titles, artists and museums come from Wikidata in the chosen language; when Wikidata has no translation, the English name is shown.

## Install

Download `Galeria-Setup-<version>.exe` from [Releases](../../releases) and run it. It installs for the current user only (no administrator rights), in `%LOCALAPPDATA%\Programs\Galeria`. The installer offers a checkbox to open Galeria when Windows starts, which adds a shortcut to your Startup folder.

**Uninstall:** Windows Settings → Apps → Galeria → Uninstall. This removes the program, the Startup shortcut, and the app's data folder (`%LOCALAPPDATA%\Galeria`). The last two wallpaper images stay in `Pictures\Galeria`; delete that folder if you want.

If you use Wallpaper Engine or a similar tool, it covers the Windows wallpaper. Pause it to see Galeria.

## How it works

- `app/galeria.py`: tray icon, shuffling, download and wallpaper change (Windows `IDesktopWallpaper`). The current wallpaper image is saved in `Pictures\Galeria` (the current one and the previous one only).
- `app/compor.py`: builds the wallpaper image with Pillow.
- `app/acervo.json`: the curated list of artworks, generated by `tools/curar.py` from [Wikidata](https://www.wikidata.org) and [Wikimedia Commons](https://commons.wikimedia.org). Selection criteria: a painting with an article in at least 12 Wikipedias; the author died in 1955 or earlier (or, with no known author, made before 1900); an image large enough for a 3840×2160 screen with at most 1.33× upscaling.
- Images are downloaded from Wikimedia Commons, at the size your screen needs.

## Build from source

Requires Python 3.12 and [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```
pip install -r requirements.txt
build.cmd
```

The output is `dist\Galeria\` (the program) and `dist\Galeria-Setup-<version>.exe` (the installer). Releases are built by GitHub Actions from this repository (`.github/workflows/build.yml`).

## Privacy

Galeria does not collect, store or send any personal data. Its only network traffic is downloading artwork images from Wikimedia Commons (`commons.wikimedia.org` and `upload.wikimedia.org`), which is subject to the [Wikimedia Foundation privacy policy](https://foundation.wikimedia.org/wiki/Policy:Privacy_policy). This program will not transfer any information to other networked systems unless specifically requested by the user.

## Português

**Galeria** troca o papel de parede do Windows por pinturas em domínio público. A cada intervalo entra uma obra nova, no tamanho exato da tela, com nome, artista, data e museu escritos num canto. Você conhece arte sem esforço, só de olhar a área de trabalho.

**Instalar:** baixe o `Galeria-Setup-<versão>.exe` em [Releases](../../releases) e rode. Instala só para o seu usuário, sem pedir administrador. O instalador tem uma caixa para abrir a Galeria quando o Windows iniciar.

**Usar:** clique com o botão direito na moldura dourada perto do relógio. O programa vem em inglês; troque em **Language** para português ou outra das 11 línguas. **Sobre esta obra** abre a página dela na Wikipédia; **Próxima obra**, **Pausar** e **Trocar a cada** (de 30 segundos a 1 dia) fazem o que dizem.

**Desinstalar:** Configurações do Windows → Aplicativos → Galeria → Desinstalar. Saem o programa, o atalho de inicialização e os dados; as duas últimas imagens ficam em `Imagens\Galeria`, para você apagar se quiser.

Se você usa o Wallpaper Engine, ele cobre o papel de parede do Windows; pause-o para ver a Galeria.
